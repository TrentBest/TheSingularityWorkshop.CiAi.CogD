# CiAi.CogD — Deterministic Vocabulary and Policy Gate

**Mission:** ProtocolAi-backed operation identity and host-side authorization prototype.

Read [the inter-repository model](https://github.com/TrentBest/TheSingularityWorkshop.CiAi/blob/development/docs/INTER_REPOSITORY_MODEL.md) and [Cog assignments](https://github.com/TrentBest/TheSingularityWorkshop.CiAi/blob/development/docs/COG_ASSIGNMENTS.md). Inspect ProtocolAi's real API before integrating. Build a tiny allowlist (observe/status and one harmless test operation), encode/resolve tests, policy-decision records, and adversarial tests proving unknown literals cannot execute.

Do not put inference, HTTP, credentials, or execution into ProtocolAi. FSM_API is not distributed persistence or GitHub transport. Work only on development; do not edit siblings/master, publish, or deploy. Deliver tests, UML, README, readiness percentage, and evidence.
